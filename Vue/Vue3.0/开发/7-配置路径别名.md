# 路径别名

+ ### 在 `vite.config.ts` 中添加配置
  - 添加 `vite` 配置  

    ```typescript
      import { defineConfig } from 'vite'
      import path from 'path'

      export default defineConfig({
        resolve: {
          // ...
          alias: [
            { find: '@', replacement: path.join(__dirname, 'src') }
          ]
        }
      })
    ```
  - 因为 `path` 为 `nodejs` 模块 ，`typescript` 不知道他的类型 需要` @types/node` 插件，补充 node 类型   

    执行 `yarn add -D @types/node`

+ ###  在 `tsconfig.json` 添加 `TypeScript` 配置

  ```json
    {
      "compilerOptions": {
        // ...
        "paths": {
          "@/*" : [
            "./src/*"
          ]
        }
      }
    }
  ```
