# 代码规范
  通过 `vite` 脚手架，生成用 `typescript` 编写的 `vue3` 项目框架，并配置 `standard` 作为代码风格。

+ ### 创建项目
  - 通过 `vite` 创建项目， 执行 `yarn create vite`
  - 选择 `vue` + `ts` 生成项目框架
  > vite 对 node 版本要求 v12 以上
  '
+ ### 项目中添加 [eslint](https://eslint.org/docs/user-guide/getting-started)
  - 安装 `yarn add eslint --dev`
  - 初始化 `yarn run eslint --init`
    + 使用方式选择强制应用一种代码规范
    + 选择 `ES6` 模块规范
    + 前端框架选择 `vue`
    + 选择使用 `typescript`
    + 运行环境选择浏览器
    + 选择流行代码规范
    + 选择 `standard` 规范
    + 配置文件类型选择 `javascript` （动态可写逻辑处理）
  - 修改 `.eslintrc.js` 配置文件  
    + 目前 `eslint` 默认配置的 `vue` 为 `vue2.x` 语法，所以需要手动改为支持 `vue3.x` 语法。
    + 需将 `eslint` 配置文件中的 `extends` 属性 `plugin:vue/essential` 替换为 `plugin:vue/vue3-strongly-recommended`

      > 更改内容查找目录 node_modules/eslint-plugin-vue/lib/config

    ``` js
      module.exports = {
        // ...
        extends: [
          'plugin:vue/vue3-strongly-recommended',
          'standard'
        ],
      }
    ```

+ ### vs-code 配置
  - 打开插件商店
    + 禁用 `vetur` 插件
    + 安装 `eslint` 插件

      > 默认读取项目中 `eslint` 配置文件，作为效验规范

    + 安装 `volar` 插件  

  - 配置
    + 找到 `设置->扩展->eslint` 
      - 将 `Enables ESlint as a formatter` 启用
      - `ESlint Run` 选项，可选**保存验证**或**实时验证**
      - 配置 eslint 保存自动修复格式风格问题
        + 设置生效文件类型，需要每种类型文件单独设置
          - 随便打开一个 `.vue` 后缀文件, `右键->使用...格式化文档->配置默认格式化程序->ESlint`
          - 随便打开一个 `.ts` 后缀文件, `右键->使用...格式化文档->配置默认格式化程序->ESlint`
          - 其他文件类型同理

        + 设置保存自动格式化，打开编辑器配置 setting.js 文件添加

          ```js
            {
              // ...
              "editor.codeActionsOnSave": {
                "source.fixAll.eslint": true
              }
            }
          ```
  
  + ### git commit hook 钩子配置
    - `package.json` 中增加 `lint` 命令  
      > **注意：mac 电脑需要在 eslint 后面的路径添加引号，否则报错**
      
      ```js
        {
          // ...
          "scripts": {
            // ...
            "lint": "eslint './src/**/*.{js,jsx,vue,ts,tsx}' --fix"
          },
        }
      ```
    - 安装 [lint-staged](https://github.com/okonet/lint-staged)
      + 执行 `npx mrm@2 lint-staged`
        > 执行完成会安装2个包 `husky` 和 `lint-staged`，主要作用分别为 `git` 钩子管理和获取 `git` 暂存区代码
    - 修改 `package.json` 中 `lint-staged` 属性

      ```js
        {
          // ...
          "lint-staged": {
            "*.{js,jsx,vue,ts,tsx}": [
              "npm run lint"
            ]
          }
        }
      ```
    - 配置运行环境  
      在 `.eslintrc.js` 增加配置
      > 解决 `defineProps` 和 `defineEmits` 警告，[查看](https://eslint.vuejs.org/user-guide/#faq)
      ```js
        {
          // ...
          env: {
            // ...
            'vue/setup-compiler-macros': true
          },
        }
      ```
  
  + ### 开发构建过程中集成 [eslint](https://eslint.org/docs/user-guide/getting-started)
    > 作用：开发过程中友好的在页面和命令行标记出不符合规范的代码
    - 安装 [vite-plugin-eslint](https://github.com/gxmari007/vite-plugin-eslint)
      + 执行 `yarn add vite-plugin-eslint --dev`
    - 在 `vite.config.ts` 配置文件中添加配置

      ```js
        // ...
        import eslintPlugin from 'vite-plugin-eslint'

        export default defineConfig({
          plugins: [
            // ...
            eslintPlugin({
              cache: false
            })
          ]
        })
      ```

      >  + 如果当前是 yarn dev 命令只会检查当前文件
      >  + 如果当前是 yarn build 命令会检查所有文件
      >  + cache 设为 false ，禁用 eslint 缓存，避免有时候已经改正的错误，页面还会报此错误  
  
  + ### commit 提交规范
    - 安装 [commitlint](https://github.com/conventional-changelog/commitlint) 
      + 安装 `commitlint cli` 和 `conventional config`
        - mac  
          `npm install --save-dev @commitlint/{config-conventional,cli}`
        - windows  
          `npm install --save-dev @commitlint/config-conventional @commitlint/cli`
      + 安装 `husky`
        > **如果按照此文档顺序操作，在安装 lint-staged 的时候，已经安装并初始化了 husky，所以可以跳过下面第一步和第二步，直接执行添加 hook 操作**
        - 执行 `yarn add husky --dev`
        - 执行 `yarn husky install`
        - 添加 hook `npx husky add .husky/commit-msg 'npx --no -- commitlint --edit "$1"'`
