# 组件通信方式
 ## `props`
  - 子组件 `child.vue`
    ```Vue
      <template>
        <div class="child-background">
          <h2>子组件</h2>
          <div>名称：{{ name }}</div>
          <div>分数：{{ count }}</div>
          <button @click="add">增加分数</button>
        </div>
      </template>

      <script setup lang="ts">
        // props 传参
        const props = defineProps(['name', 'count'])  
        // 自定义事件
        const $emit = defineEmits(['add'])  

        const add = () => {
          $emit('add', props.count + 1)
        }
      </script>

      <style scoped>
        .child-background {
          background-color: chartreuse;
          height: 200px;
          width: 200px;
        }
      </style>
    ``` 
  - 父组件 `App.vue`   
    ```Vue
      <script setup lang="ts">
        import { ref } from 'vue'
        import Child from './components/child.vue' 

        const name = ref('张三')
        const count = ref(10)

        const handleAdd = (value: number) => {
          count.value = value
        }
      </script>

      <template>
        <div class="background">
          <h2>父组件</h2>
          <hr/>
          <Child :name="name" :count="count" @add="handleAdd"></Child>
        </div>
      </template>

      <style scoped>
        .background {
          display: flex;
          flex-direction: column;
          align-items: center;
          background-color: aqua;
          height: 400px;
          width: 400px;
        }
      </style>
    ```

+ ## `event bus` (通过 `mitt` 插件 实现)
  - 安装 `mitt` 插件
    `pnpm add mitt --save`
  - 添加 `src/utils/index.ts` 文件  

    ```typescript
      import mitt from 'mitt'

      type Events = {
        add: number // 要使用的 方法（add）: 参数类型：（number）
      };

      const emitter= mitt<Events>()

      export default emitter
    ```
  - App.vue
    ```Vue
      <script setup lang="ts">
        import Child from './components/child.vue'
        import Child2 from './components/child2.vue'

      </script>

      <template>
        <div class="background">
          <h2>父组件</h2>
          <div class="child">
            <Child></Child>
            <Child2></Child2>
          </div>
        </div>
      </template>

      <style scoped>
        .background {
          background-color: aqua;
          height: 400px;
          width: 800px;
        }

        .child {
          height: 400px;
          display: flex;
          justify-content: space-between;
          align-items: center;
        }
      </style>
    ```
  - 添加 `src/components/child.vue` 文件
    ```Vue
      <template>
        <div class="child-background">
          <h2>第一个子组件</h2>
          <div>余额：{{ money }}</div>
        </div>
      </template>

      <script setup lang="ts">

      import emitter from '../utils/index'
      import { ref, onMounted } from 'vue'

      const money = ref(0)

      onMounted(() => {
        emitter.on('add', count => {
          money.value += count
        })
      })

      </script>

      <style scoped>
        .child-background {
          background-color: chartreuse;
          height: 200px;
          width: 200px;
        }
      </style>
    ```
  - 添加 `src/components/child2.vue` 文件
    ```Vue
      <template>
        <div class="child-background">
          <h2>第二个子组件</h2>
          <button @click="add">转账</button>
        </div>
      </template>

      <script lang="ts" setup>
        import emitter from '../utils/index'

        const add = ()=> {
          emitter.emit('add', 1)
        }
      </script>

      <style scoped>
        .child-background {
          background-color: blueviolet;
          height: 200px;
          width: 200px;
        }
      </style>
    ```
+ ## `v-model`
  - 说明  
    自定义节点上可以有多个 `v-model` ，写法为 `<child v-model:"变量1" v-model:"变量2"></child>`，子组件用 `defineProps` 来接收父组件传递过来的参数。 使用 `defineEmits` 接收参数默认更新事件 `update:变量1` 、 `update:变量2` ，子组件触发更新事件后，父组件不用写其方法实现，变量默认更新。  

  - 示例
    + `App.vue`
      ```Vue
      <script setup lang="ts">
        import Child from './components/child.vue'
        import { ref } from 'vue'
        const money = ref(0)
        const food = ref(0)
      </script>

      <template>
        <div class="background">
          <h2>父组件</h2>
          <div class="child">
            <Child v-model:food="food" v-model:money="money"></Child>
          </div>
        </div>
      </template>

      <style scoped>
        .background {
          background-color: aqua;
          height: 400px;
          width: 800px;
        }

        .child {
          height: 400px;
          display: flex;
          justify-content: space-between;
          align-items: center;
        }
      </style>

      ```
    + `child.vue`
      ```html
      <template>
        <div class="child-background">
          <h2>子组件</h2>
          <div>金币：{{ money }}</div>
          <div>食物：{{ food }}</div>
          <button @click="handleMoneyClick">增加金币</button>
          <button @click="handleFoodClick">增加食物</button>
        </div>
      </template>

      <script setup lang="ts">
        const props = defineProps(['money', 'food'])

        const $emit = defineEmits(['update:money', 'update:food'])

        const handleMoneyClick = ()=> $emit('update:money', props.money + 1)
        const handleFoodClick = () => $emit('update:food', props.food + 100)

      </script>

      <style scoped>
        .child-background {
          background-color: chartreuse;
          height: 200px;
          width: 200px;
        }
      </style>
      ```  

+ ## `useAttrs`
  - 说明  
    `useAttrs` 获取节点上的所有属性和事件，类似 `props` 方式。如果 `useAttrs` 和 `props` 同时存在， `props` 优先级 大于 `useAttrs` ，也就是说， `porps` 中获取的值不会再出现在 `useAttrs` 里。
  - 示例
    + 父组件 `App.vue`  
      ```Vue
        <script setup lang="ts">
          import MyButton from './components/child.vue'
          import { ref } from 'vue'

          const title = ref('子组件')

          const add = (text: string) => {
            console.log(text)
          }
        </script>

        <template>
          <div class="background">
            <h2>父组件</h2>
            <div class="child">
              <MyButton type="button" :title="title" value="点我" @add="add"></MyButton>
            </div>
          </div>
        </template>

        <style scoped>
          .background {
            background-color: aqua;
            height: 400px;
            width: 800px;
          }

          .child {
            height: 400px;
            display: flex;
            justify-content: space-between;
            align-items: center;
          }
        </style>
      ```
    + 子组件 `child.vue`
      ```Vue
        <template>
          <div class="child-background" :title="placeholder">
            <h2>子组件</h2>
            <input :="$attrs" @click="handleClick"/>
          </div>
        </template>

        <script setup lang="ts">
          import { useAttrs } from 'vue';

          const $attrs = useAttrs()
          const props = defineProps(['placeholder'])
          const $emit = defineEmits(['add'])

          const placeholder = props.placeholder

          const handleClick = () => {
            $emit('add', '点击成功')
          }

        </script>

        <style scoped>
          .child-background {
            background-color: chartreuse;
            height: 200px;
            width: 200px;
          }
        </style>
      ```
    > `:="$attrs"` 等同于 `v-bind="{键1: 值1, 键2: 值2, 方法键1: 方法值1}"`, 其中 `v-bind` 可以简写成 `:`，所以最终写法为 `:="$attrs"`

+ ## `ref & parent`
    - `ref` 从父组件获取子组件的属性和方法
      + 父组件 `App.vue`   
        ```Vue
          <script setup lang="ts">
            import { ref } from 'vue'

            import child, { ISon } from './components/child.vue'

            const son = ref<ISon | undefined>()

            const money = ref(100000)

            const transform = (value: number) => {
              money.value -= value
              if(son.value) son.value.money += value
            }
          </script>

          <template>
            <div class="background">
              <h2>父亲</h2>
              <div>余额：{{ money }}</div>
              <button @click="transform(1000)">转给儿子 1000 元</button>
              <div class="child">
                <child ref="son"></child>
              </div>
            </div>
          </template>

          <style scoped>
            .background {
              background-color: aqua;
              height: 600px;
              width: 800px;
            }

            .child {
              height: 400px;
              display: flex;
              justify-content: space-between;
              align-items: center;
            }
          </style>
        ``` 

      + 子组件 `child.vue`
        ```Vue
          <template>
            <div class="child-background" >
              <h2>我是儿子</h2>
              <div>余额: {{ money }}</div>
            </div>
          </template>

          <script setup lang="ts">
            import { ref } from 'vue'

            const money = ref(1000)

            defineExpose({ money })

            // 暴露给父组件的类型
            export interface ISon {
              money: number
            }

          </script>

          <style scoped>
            .child-background {
              background-color: chartreuse;
              height: 200px;
              width: 200px;
            }
          </style>
        ``` 

    - `$parent` 从子组件获取父组件的属性和方法
      + 父节点 `App.vue`  
        ```Vue
          <script setup lang="ts">
            import { ref } from 'vue'
            import child from './components/child.vue'

            const money = ref(100000)

            defineExpose({money})

          </script>

          <template>
            <div class="background">
              <h2>父亲</h2>
              <div>余额：{{ money }}</div>
              <div class="child">
                <child></child>
              </div>
            </div>
          </template>

          <style scoped>
            .background {
              background-color: aqua;
              height: 600px;
              width: 800px;
            }

            .child {
              height: 400px;
              display: flex;
              justify-content: space-between;
              align-items: center;
            }
          </style>
        ``` 
      + 子节点 `child.vue`  
        ```Vue
          <template>
            <div class="child-background" >
              <h2>我是儿子</h2>
              <div>余额: {{ money }}</div>
              <button @click="transform($parent, 10)">转给父亲10元</button>
            </div>
          </template>

          <script setup lang="ts">
            import {ref } from 'vue'

            const money = ref(10000)

            interface IParent {
              money: number
            }

            const transform = ($parent: any, value: number) => {
              money.value -= value
              $parent.money += value
            }
          </script>

          <style scoped>
            .child-background {
              background-color: chartreuse;
              height: 200px;
              width: 200px;
            }
          </style>
        ```
