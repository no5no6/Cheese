# 微前端

#### 微前端不是一项新的技术，而是一种软件架构理念，他将一个应用拆分成多个可独立开发、独立部署、独立运行的微型应用，然后再将这些微型应用组成为一个整体应用的架构模式。  

## 特点
+ 增量开发、增量迁移
+ 每个微应用都可以独立发布
+ 每个微应用可使用不同的框架（或不使用框架）开发

## 按粒度区分粒度
+ 应用级别
  - [乾坤](https://github.com/umijs/qiankun)

+ 模块级别
  - [single-spa](https://github.com/single-spa/single-spa)
  - [micro-app](https://github.com/micro-zoe/micro-app)

## 模块联邦(实现了模块的分发、共享)
  + SystemJS
    - SystemJS动态加载的模块必须是SystemJS模块或者UMD模块
    - SystemJS的模块依赖关系是在运行时确定的，即通过importMap
  + Webpack5模块联邦
    - 而Webpack5模块联邦的依赖关系是在编译时确定的，即读取编译时生成的remoteEntry.js来分析依赖
